# 🏥 Medical AI RAG System

A RAG-powered medical assistant built on synthetic 
patient data using ChromaDB.

## What it Does
- Generates 15 synthetic patient records
- Converts records to AI-readable text documents
- Stores in ChromaDB vector database
- Answers medical questions using semantic search

## Tech Stack
- Python
- ChromaDB
- Pandas
- Google Colab

## How to Run
1. Open Google Colab
2. Install: !pip install chromadb pandas
3. Run patient_data_training.py
4. Query patients with plain English

## Example Queries
- "Which patients have diabetes?"
- "Who is on Warfarin?"
- "Patients with breathing problems?"
